# UniPath Backend

Production-oriented FastAPI backend skeleton for:
- University Explorer
- Admit Predictor
- Admission Statistics
- AI Chat Advisor (RAG)
- Application Tracker
- Watchlist + Notes
- Similar Profile Finder
- University Comparison

## Quick Start (after implementation)

```bash
uv sync
alembic upgrade head
uvicorn app.main:app --reload
```
